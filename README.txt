ПОРТФОЛИО ТИМОФЕЯ ДЕРЕНСКОГО

Файлы сайта:
- index.html       главная
- musician.html    отдельная страница музыканта
- programmer.html  страница программиста и проекты
- learn.html       руководство «Как стать программистом?»
- style.css        общий дизайн и адаптивность
- script.js        меню, год в подвале и кнопки копирования
- starter-files/   скачиваемые примеры HTML, CSS и JS
- starter-files.zip архив примеров для начинающих

ПУБЛИКАЦИЯ НА GITHUB PAGES
1. Создай новый репозиторий на GitHub.
2. Загрузи все файлы и папку starter-files в корень репозитория.
3. Открой Settings -> Pages.
4. В разделе Build and deployment выбери Deploy from a branch, ветку main и папку /(root).
5. Сохрани настройки и дождись публикации.

Главный файл должен называться index.html. GitHub Pages поддерживает статические HTML/CSS/JS-сайты.
Перед публикацией проверь, что папка starter-files и все файлы загружены, а ссылки открываются.
